Import a saved Reddit thread

lurkd never contacts Reddit. Open the thread in your own browser, add .json to the end of its address and save the page that opens as a file, then choose that file here. The import is for your own use: one thread at a time, kept on this computer. Reddit's User Agreement forbids collecting its content without permission, so the decision to import a thread, and the responsibility for it, are yours.
